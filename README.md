# 🍜 FoodChow

A responsive food ordering web application built with React and Vite.

## 📋 Task

Fetch and parse the data from the provided API, and display it by replicating the layout and design from the reference URL.

## 🚀 Live Demo

https://foodchow-task.vercel.app

## ✨ Features

- Fetches and displays menu data from the provided API
- Browse food categories
- Search menu items
- Add items to cart
- Dynamic cart quantity and total
- Size selection
- Checkout page
- Login & Sign Up popup
- Responsive UI
 
## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- CSS
- REST API
- Lucide React
- npm
- Vercel (Deployment)
- Git & GitHub
